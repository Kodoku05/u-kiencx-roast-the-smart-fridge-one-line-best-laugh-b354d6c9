A one-line roast of a smart fridge's interior-camera photos and its failure to keep lettuce alive.

Run `python3 main.py` with Python 3 to write the entry as UTF-8 to `/output/entry.txt`.
Uses only the standard library, with no network or arguments.

Built for [Roast the Smart Fridge: One Line, Best Laugh Wins](https://make.fun/bounty/u-kiencx-roast-the-smart-fridge-one-line-best-laugh-b354d6c9).
